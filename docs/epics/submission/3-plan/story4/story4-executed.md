# Story 4 실행 기록 — README 테스트 섹션

## 무엇을 했는가

README.md에 테스트 섹션을 추가했다. Spring 자동화 테스트가 아닌, 앱을 직접 띄우고 curl로 입력·출력을 확인하는 시나리오 형태로 작성했다.

## 결정 사항

- **curl 시나리오 방식** — 검토자가 make up 후 순서대로 따라가며 직접 응답을 확인하는 구조. 자동화 테스트 목록 나열보다 실제 동작을 눈으로 볼 수 있는 방식.
- **응답값은 실제 실행으로 확인** — 모든 예상 응답값을 Docker로 앱을 띄운 뒤 curl로 직접 확인해 기재했다.
- **비즈니스 엣지 케이스 포함** — 해피 패스 외에 재고 부족(409)·재고 정확히 소진·없는 상품 출고/조회(404) 3가지를 추가했다.
