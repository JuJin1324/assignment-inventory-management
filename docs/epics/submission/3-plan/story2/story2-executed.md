## 무엇을 했는가

README.md에 **문서 지도**와 **코드 구조** 두 섹션을 추가했다.

## 결정 사항

- **읽는 순서는 4단계로** — assignment → structure → ADR → epics 순서. 요구사항에서 출발해 모델·결정·구현 흐름으로 깊이를 더해가는 구조.
- **핵심 ADR 4개만 표로** — 001(아키텍처)·009(도메인 모델)·012(동시성)·003(테스트). 나머지는 에픽 내부에서 맥락과 함께 읽게 둔다.
- **요구사항→구현 연결은 표로** — 과제 3개 요구사항(입고·출고·재고 조회)과 동시성 제어 항목을 API + 에픽 경로로 바로 연결.
- **코드 구조는 패키지 트리로** — 레이어 이름보다 실제 패키지 경로가 구체적. ADR·modeling 링크로 설계 근거를 이어붙였다.
